# Test Plan: AI Box Catalog

Generated by `/plan-eng-review` on 2026-06-29
Related plan: [engineering-plan.md](./engineering-plan.md)

## Affected Pages / Routes

- `/` or `/boxes` — box list, empty state, search entry.
- `/boxes/new` — create a new numbered box.
- `/boxes/:boxId` — box card, items, photos, QR, edit actions.
- `/boxes/:boxId/photos` — add photos and start extraction.
- `/boxes/:boxId/review/:jobId` — review AI suggestions, add all, add selected,
  rename, delete suggestions.
- `/search?q=...` or inline search state — ranked box candidates with photo evidence.
- `/qr/:boxId` or equivalent deep link — opens the box by stable ID.

## Critical Paths

- Create first box, see number, see QR.
- Open existing box and add an item manually.
- Delete an item and verify search no longer returns it.
- Add photos, receive AI suggestions, add all suggestions.
- Add photos, receive AI suggestions, add selected suggestions only.
- Rename one AI suggestion before accepting it.
- Search `black gloves` and see candidate box plus photo evidence.
- Open a QR/deep link and land on the correct box.

## Key Interactions to Verify

- Box number uniqueness validation.
- QR route uses stable `boxId`, not mutable box number.
- Manual item add blocks empty names.
- Delete item has confirmation or undo.
- Photo capture works with camera input.
- File upload fallback works if camera permission is denied.
- Extraction job shows loading, failure, retry, and manual fallback states.
- Applying suggestions is idempotent and does not duplicate items.
- Search ranks multiple candidate boxes rather than claiming false certainty.

## Edge Cases

- Empty catalog.
- Box with no items.
- Box with no photos.
- Duplicate box number.
- Duplicate AI suggestions.
- AI returns invalid structured output.
- AI request times out.
- User closes or reloads app during extraction.
- User adds manual item while extraction job is pending.
- QR points to deleted or missing box.
- Long item names.
- 100+ items in one box.
- No search results.
- Multiple weak search matches.

## AI Eval Fixture

Create a fixture before wiring live AI:

- 3 real boxes.
- 2-3 photos per box.
- Expected item list per box.
- 5 search queries per box.

Minimum eval:

- AI suggestions include at least 70% of obvious visible items.
- For each fixture query, the correct box appears in the top 2 results.
- False positives are acceptable only when the correct result is not hidden and photo
  evidence is shown.

## Test Types

- Unit: repository methods, suggestion apply, search scoring, QR payload generation.
- E2E: create box, manual edit, photo review, search, QR navigation.
- Eval: AI extraction quality and search recall over the fixture.

## Current E2E Coverage

- `e2e/create-manual-search.yaml` covers first box creation, manual item add,
  search candidate display, and item deletion.
- `e2e/qr-missing.yaml` covers recoverable QR/deep-link not-found behavior.

Camera/gallery E2E coverage still needs an Android fixture and device-specific
handling for system pickers.
